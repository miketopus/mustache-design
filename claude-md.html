01 / Por qué

Una sola fuente de reglas, para todos.

Hoy cada persona le explica Rappi a Claude a su manera. Con Mustache for Claude, todos parten del mismo sistema: el de Figma.

Tokens, no hex

Claude elige por uso (ink/error, background/offer) y el dark mode sale solo. Lo mismo que pedimos en Figma.

Suena a Rappi

Incluye la guía de voz y tono: tuteo, verbos de acción, errores que dicen qué hacer. Copies listos para revisar, no para reescribir.

Handoff más corto

Cada entrega trae una tabla de tokens usados. De prompt a Figma o a código sin traducir valores a mano.

03 / Instalar

Listo en 2 minutos.

Elige dónde usas Claude. Si tu equipo usa un plan Team o Enterprise, lo ideal es que un owner la active para toda la organización.

En claude.ai

Una vez instalada, no tienes que nombrarla: Claude la usa cuando pides algo de Rappi.

  1. Descarga mustache-ds-skill.zip. No lo descomprimas.
  2. En Claude ve a Customize › Skills.
  3. Toca +, luego Create skill › Upload a skill y elige el .zip.
  4. Actívala y pruébala: Diseña el estado vacío del carrito.

Requiere tener activa la opción code execution and file creation en la configuración de Claude.

En un Project

Ideal para squads: todos los chats del Project heredan las reglas.

  1. Descarga mustache-ds-guidelines.md.
  2. Abre o crea un Project (ej. "Checkout Design").
  3. En Project knowledge, sube el archivo.
  4. Opcional: en las instrucciones del Project escribe Sigue siempre Mustache (mustache-ds-guidelines.md).

El .md no se actualiza solo. Cuando publiquemos una versión nueva, reemplaza el archivo.

En Claude Code

Para prototipos en código y repos de producto.

  1. Descomprime el .zip.
  2. Copia la carpeta mustache-ds/ en .claude/skills/ de tu repo (para todo el equipo) o en ~/.claude/skills/ (solo para ti).
  3. Importa assets/tokens.css en tu CSS y usa las variables --rp-*.

Para toda la organización

La mejor opción a escala: una sola versión, visible para todas las personas de Rappi.

  1. Un owner del plan Team o Enterprise entra a Organization settings › Plugins & skills.
  2. Sube mustache-ds-skill.zip.
  3. La Skill aparece automáticamente para todos los miembros.

¿No eres owner? Comparte esta página con el equipo de IT o de Plataforma de IA de Rappi y pídeles que la provisionen.

¿Cada cuánto se actualiza? Cada vez que publicamos cambios en el sitio o en las reglas. Si cambió algo del sistema y no lo ves, revisa la versión y la fecha arriba en esta página y descarga de nuevo.

¿Skill o archivo .md? ¿Cuál me conviene?

La Skill es mejor para uso diario: Claude la activa sola y solo lee lo que necesita, así que no ocupa contexto en chats que no son de diseño. El .md es más simple y sirve en cualquier Project, pero siempre está cargado y hay que reemplazarlo a mano cuando cambie.

¿Se actualiza sola?

Si la instalaste tú, no: descarga la nueva versión cuando la publiquemos aquí. Si la provisiona un owner para toda la organización, se actualiza para todos desde un solo lugar.

¿Reemplaza a Figma?

No. Figma sigue siendo la fuente de verdad. El kit es una foto de las librerías para que Claude razone igual que nosotros. Si ves una diferencia, gana Figma, y avísanos.

¿Qué pasa si Claude usa un color que no existe?

La Skill le prohíbe inventar hex. Si falta un token, lo marca como sin token oficial y propone el más cercano. Si aun así lo hace, pídele: Revisa esto contra Mustache.

¿Puedo usarla con el MCP de Figma?

Sí, y es la mejor combinación. Con el conector de Figma, Claude lee tu frame y lo compara contra las reglas de la Skill.

¿Por qué no veo la fuente PP Object Sans en los mockups?

Es una fuente licenciada y no está en Google Fonts. Los prototipos HTML usan Inter como aproximación; el producto final usa PP Object Sans.
